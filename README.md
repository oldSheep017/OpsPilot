# OpsPilot

OpsPilot is an AI-powered operations assistant designed for developers.

It helps users inspect project status, retrieve Git information, analyze logs,
and troubleshoot deployment issues through natural language.

## Planned Features

- Project status monitoring
- Git branch and commit inspection
- Log retrieval and analysis
- AI agent tool calling
- Deployment document retrieval
- Human confirmation for sensitive operations

## Tech Stack

- React
- TypeScript
- Python
- FastAPI
- LangGraph
- PostgreSQL
- pgvector
- Docker
